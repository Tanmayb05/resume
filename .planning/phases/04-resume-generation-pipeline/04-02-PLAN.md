**Step 2: Create src/resume/trimmer.py**

Implement a dataclass `LoopResult` and async function `trim_loop(selected_content, job_dir, llm_client, config, render_fn, compile_fn, analyze_fn) -> LoopResult`.

```python
from dataclasses import dataclass, field
from pathlib import Path
from typing import Optional

@dataclass
class LoopResult:
    success: bool
    iteration_count: int
    pdf_path: Optional[Path] = None
    tex_path: Optional[Path] = None
    page_fit_warning: bool = False
    whitespace_warning: bool = False
    error: Optional[str] = None
```

Implement `trim_loop` with this exact logic:

```
max_iterations = config.max_iterations (read from AppConfig; default 5)
iteration = 0
consecutive_failures = 0
all_iteration_paths = []   # track all (tex, pdf) for cleanup

while iteration < max_iterations:
    iteration += 1
    tex_path = job_dir / f"resume_iter_{iteration}.tex"
    pdf_path = job_dir / f"resume_iter_{iteration}.pdf"
    all_iteration_paths.append((tex_path, pdf_path))

    # Render .tex
    render_fn(selected_content, tex_path)   # calls render_resume_tex

    # Compile to PDF
    compile_result = compile_fn(tex_path, job_dir)  # calls compile_tex
    if not compile_result["success"]:
        consecutive_failures += 1
        logger.warning("Compile failed iter %d: %s", iteration, compile_result.get("error_type"))
        if consecutive_failures >= 2:
            logger.error("Two consecutive compile failures — stopping")
            return LoopResult(
                success=False,
                iteration_count=iteration,
                error="Two consecutive compilation failures",
            )
        # Trim and retry (even after compile failure — truncate further)
        selected_content = _trim_longest_bullets(selected_content, pct=0.15, llm_client=llm_client, config=config)
        continue

    consecutive_failures = 0
    analysis = analyze_fn(str(pdf_path))   # calls analyze_pdf

    page_count = analysis["page_count"]
    page_height = analysis["page_height_inches"]
    whitespace_ratio = analysis["whitespace_ratio"]

    logger.info("Iter %d: pages=%d height=%.1fin whitespace=%.2f", iteration, page_count, page_height, whitespace_ratio)

    # Success condition: page_count == 1 AND height <= 11.5in
    if page_count == 1 and page_height <= 11.5:
        # Check for over-trimming (whitespace_warning)
        whitespace_warning = whitespace_ratio > 0.40
        # Cleanup intermediate iterations (keep only final success)
        _cleanup_iterations(all_iteration_paths, keep_tex=tex_path, keep_pdf=pdf_path)
        return LoopResult(
            success=True,
            iteration_count=iteration,
            pdf_path=pdf_path,
            tex_path=tex_path,
            whitespace_warning=whitespace_warning,
        )

    # Overflow: page_count > 1 or height > 11.5in
    if iteration >= max_iterations:
        logger.warning("Max iterations (%d) reached without fitting to one page", max_iterations)
        _cleanup_iterations(all_iteration_paths, keep_tex=tex_path, keep_pdf=pdf_path)
        return LoopResult(
            success=False,
            iteration_count=iteration,
            pdf_path=pdf_path,
            tex_path=tex_path,
            page_fit_warning=True,
        )

    # Trim and retry
    selected_content = await _trim_longest_bullets(selected_content, pct=0.15, llm_client=llm_client, config=config)

# Should not reach here
return LoopResult(success=False, iteration_count=iteration, error="Unexpected loop exit")
```

2. Build list: `[(section_type, entry_idx, bullet_idx, bullet_text, char_count)]`
3. Sort by char_count descending

```python
from dataclasses import dataclass, field
from typing import List

@dataclass
class ValidationResult:
    success: bool
    validation_warning: bool = False
    violations: List[str] = field(default_factory=list)
```

Implement `validate_content(selected_content: dict, master_resume: dict) -> ValidationResult`:

This is a PURE Python function (no LLM, no async). Uses structured field diff — NOT PDF text extraction, NOT regex NER.

Validation logic (per CONTEXT.md locked decision — structured diff, warn-and-return):

1. **Validate skills:**
   - Extract skills from selected_content: find section with `type == "technical_skills"`, iterate `lines`, flatten all `items` lists → `selected_skills: set[str]`
   - Extract master skills: from master_resume `technical_skills` (flatten all categories) → `master_skills_lower: dict[str, str]` (lowercase → original)
   - For each selected skill: normalize to lowercase, strip version numbers (e.g., "Python 3.10" → "python"), check if normalized form is a substring of any master skill (case-insensitive). If no match found → violation.
   - Normalization: `re.sub(r'\s+\d[\d.]*$', '', skill).strip().lower()` (strips trailing version numbers)

2. **Validate companies:**
   - Extract companies from selected_content: find sections with `type == "work_experience"`, collect `entry["company"]` values → `selected_companies: set[str]`
   - Extract master companies: from master_resume `work_experience`, collect `exp["company"]` → `master_companies: set[str]`
   - Check: each selected company must be in master_companies (exact case-insensitive match)
   - Mismatches → violation

3. **Validate projects:**
   - Extract project titles from selected_content: find sections with `type == "projects_and_research"`, collect `entry["title"]` → `selected_projects: set[str]`
   - Extract master project titles from master_resume (look for `projects` or `projects_and_research` key) → `master_projects: set[str]`
   - Check: each selected project title must be in master projects (case-insensitive)
   - Mismatches → violation

4. **Aggregate and return:**
   ```python
   if violations:
       logger.warning("Validation violations found: %s", violations)
       return ValidationResult(success=True, validation_warning=True, violations=violations)
   return ValidationResult(success=True, validation_warning=False)
   ```
   **NEVER raise an exception — always return ValidationResult. This is a job-hunt tool; validation failure is a warning, not a crash (per CONTEXT.md Claude's Discretion: warn-and-return).**

5. **Edge case handling:**
   - If selected_content is missing expected sections: log warning, skip that check (don't raise)
   - If master_resume is missing expected keys: log warning, skip that check

**Imports:** `re`, `logging`, `dataclasses`, `typing`
