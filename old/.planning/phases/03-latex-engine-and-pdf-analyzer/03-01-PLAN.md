Create src/latex/renderer.py implementing render_resume_tex(payload: dict, output_path: Path) -> Path.

Key implementation requirements:

1. **Jinja2 Environment with custom delimiters** (CRITICAL — default {{ }} conflicts with LaTeX):
   ```python
   from jinja2 import Environment, FileSystemLoader, StrictUndefined

   env = Environment(
       loader=FileSystemLoader(str(Path(__file__).parent.parent.parent / "templates")),
       undefined=StrictUndefined,
       variable_start_string='((*',
       variable_end_string='*))',
       block_start_string='((%',
       block_end_string='%))',
       comment_start_string='((#',
       comment_end_string='#))',
       trim_blocks=True,
       lstrip_blocks=True,
   )
   ```
   Note: loader points to the project-root `templates/` directory (three levels up from `src/latex/`).

2. **latex_escape Jinja2 filter** — register on env before getting template:
   ```python
   LATEX_SPECIAL = {'&': r'\&', '%': r'\%', '$': r'\$', '#': r'\#',
                    '_': r'\_', '{': r'\{', '}': r'\}', '~': r'\textasciitilde{}',
                    '^': r'\textasciicircum{}', '\\': r'\textbackslash{}'}

   def latex_escape(value: str) -> str:
       # Must escape backslash first to avoid double-escaping
       result = str(value).replace('\\', r'\textbackslash{}')
       for char, replacement in LATEX_SPECIAL.items():
           if char != '\\':
               result = result.replace(char, replacement)
       return result

   env.filters['latex_escape'] = latex_escape
   ```

3. **render_resume_tex signature**:
   ```python
   def render_resume_tex(payload: dict, output_path: Path) -> Path:
       """Render resume JSON payload through resume_template.tex.j2 and save atomically.

       Args:
           payload: Structured resume dict matching resume_json_template.json schema.
           output_path: Full absolute path for the output .tex file
                        (e.g., Path("data/acme/resume_iter_0.tex")).
                        Parent directory must exist.
       Returns:
           output_path (the written file path).
       Raises:
           jinja2.UndefinedError: If template references variable not in payload.
           OSError: If parent directory doesn't exist or write fails.
       """
   ```

4. **Atomic write pattern** (from Phase 1 established pattern):
   ```python
   import tempfile, os

   tex_content = template.render(**payload)
   tmp_fd, tmp_path = tempfile.mkstemp(dir=output_path.parent, suffix='.tex')
   try:
       with os.fdopen(tmp_fd, 'w', encoding='utf-8') as f:
           f.write(tex_content)
           f.flush()
           os.fsync(f.fileno())
   except Exception:
       os.unlink(tmp_path)
       raise
   os.replace(tmp_path, output_path)
   return output_path
   ```

5. **Module-level cached environment** — same pattern as Phase 2's _JINJA_ENV:

   ```python
   _LATEX_ENV: Environment | None = None

   def _get_latex_env() -> Environment:
       global _LATEX_ENV
       if _LATEX_ENV is None:
           # build env + register filter
       return _LATEX_ENV
   ```

Create templates/resume_template.tex.j2 by converting the existing templates/resume_template.tex into a Jinja2 template.

The JSON payload structure is defined in templates/resume_json_template.json. Key top-level keys: `header`, `sections` (array with types: education, technical_skills, work_experience, projects_and_research, extracurricular).

**Delimiter rules:**
- Variables: `((* variable | latex_escape *))` for user-supplied strings (name, company, role, dates, bullets, etc.)
- Block tags: `((%  %))` for if/for loops
- Comments: `(( # ... # ))` for comments (but avoid in final template)

**Apply latex_escape to ALL user-supplied text fields:**
- header.name, all contactLine[].text values
- education entries: degree, institution, dates, courseworkLine
- skills lines: label, each item in items array
- experience entries: company, role, dates, each techStack item, each bullet
- project entries: title, date, each techBracket item, linkText (if present), each bullet
- extracurricular bullets

**Template structure to produce (matching resume_template.tex layout exactly):**

1. Keep the full LaTeX preamble (documentclass, usepackage blocks, \definecolor, custom environments) as-is — this is static LaTeX, no Jinja2 needed.

2. In \begin{document} section, replace hardcoded content with Jinja2 loops:

Header section:
```latex
    \begin{header}
        \fontsize{((* header.nameFontPt *)) pt}{((* header.nameLineHeightPt *)) pt}\selectfont ((* header.name | latex_escape *))

        \normalsize
        ((% for item in header.contactLine %))
        \mbox{((* item.text | latex_escape *))}\kern 1.0 pt%
        ((% if not loop.last %))
        \AND\kern 1.0 pt%
        ((% endif %))
        ((% endfor %))
    \end{header}
```

Sections loop (iterate over sections array, dispatch on type):
```latex
((% for section in sections %))

    \begin{onecolentry}
    ((* entry.courseworkLine | latex_escape *))
    \end{onecolentry}
    ((% if not loop.last %))
    \vspace{0.10 cm}
    ((% endif %))
    ((% endfor %))
((% elif section.type == 'technical_skills' %))
...
((% elif section.type == 'work_experience' %))
...
((% elif section.type == 'projects_and_research' %))
...
((% elif section.type == 'extracurricular' %))

((% endfor %))
```
