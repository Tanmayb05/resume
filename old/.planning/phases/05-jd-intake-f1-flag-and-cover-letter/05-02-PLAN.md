    3. ADD JDService class following ResumeService pattern (src/resume/service.py is the reference):

       Constructor: __init__(self, config: AppConfig, llm_client: LLMClient)

       Public method: async def parse_and_persist(self, jd_text: str, store: JobStore) -> JDParseResult

       Implementation:
         Step 1 — F1 detection (pure Python, no LLM, done before parse):
           f1_flag = detect_f1_sponsorship(jd_text)

         Step 2 — LLM parse with retry (call private _parse_jd):
           try:
               parsed = await self._parse_jd(jd_text)
           except ValueError as exc:
               return JDParseResult(success=False, error=str(exc))
           except LLMError as exc:
               return JDParseResult(success=False, error=f"LLM error: {exc}")
           except Exception as exc:
               return JDParseResult(success=False, error=f"JD parse failed: {exc}")

         Step 3 — Validate raw dict BEFORE constructing JobRecord:
           REQUIRED = ("company", "role", "location")
           if not all(parsed.get(f) for f in REQUIRED):
               return JDParseResult(success=False, error="Missing required fields after parse")

         Step 4 — Allocate job directory (collision-safe via JobStore):
           job_dir = store.new_job_dir(parsed["company"], parsed["role"])
           job_dir.mkdir(parents=True, exist_ok=True)

         Step 5 — Construct JobRecord:
           record = JobRecord(
               company=parsed["company"],
               role=parsed["role"],
               location=parsed["location"],
               job_dir=str(job_dir),
               jd_text=jd_text,
               f1_sponsorship_available=f1_flag,
               status=JobStatus.DISCOVERED,
           )
           Add any extra parsed fields that exist on JobRecord (skills_required, responsibilities,
           requirements, employment_type) as Optional fields — check job_record.py for actual field names
           before assigning to avoid AttributeError.

         Step 6 — Persist:
           store.write(record)
           return JDParseResult(success=True, job_record=record)

       Private method: async def _parse_jd(self, jd_text: str) -> dict
         MAX_PARSE_ATTEMPTS = 2
         For attempt 1: load_prompt("parse_job_description", jd_text=jd_text)
         For attempt 2 (if required fields missing): re-call load_prompt with strict_mode=True IF
           the parse_job_description.md template supports strict_mode, otherwise repeat the same prompt
           with an appended instruction: "\n\nIMPORTANT: company, role, and location are required.
           If any are unclear from the JD, make your best inference. Do not return null for these fields."
         After MAX_PARSE_ATTEMPTS: raise ValueError("JD parse failed: company, role, or location
           missing after 2 attempts")

    CRITICAL RULES:
    - Never construct JobRecord before validating required fields from the raw dict
    - Never call store.write() before job_dir exists on disk
    - Use store.new_job_dir() — never construct job_dir manually with string concat
    - Do NOT use or import from src/llm.py or src/cover_letter_generator.py (legacy — deprecated)
    - The detect_f1_sponsorship() function is already in this file from Plan 01 — do not redeclare it
